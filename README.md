# AI-Based Object Detection and Tracking System

## Project Overview
This project is an AI-based object detection and tracking system developed using Python, YOLO, OpenCV, and Streamlit.

It detects objects in uploaded images and videos and displays bounding boxes and labels.

## Features
- Image-based object detection
- Video-based object detection
- Object tracking in videos
- Bounding boxes and object labels
- Object counting
- Download processed video

## Technologies Used
- Python
- YOLO (Ultralytics)
- OpenCV
- Streamlit
- NumPy
- Pillow

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```

## How to Use
1. Open the Streamlit application.
2. Upload an image or video.
3. Select Object Detection or Object Tracking.
4. Start processing.
5. View the detection results.
